# Bitcoin Data Table

A React + TypeScript + Vite web app that fetches Bitcoin market data and displays it in a styled table with pagination.

## Features

- Styled table using Tailwind CSS
- Shows 20 days per page
- Pagination to browse all days returned by the API
- navbar
- Home-page

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Requirements

- Node.js 18+
